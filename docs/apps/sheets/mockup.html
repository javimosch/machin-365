Machin Sheets: proposed first version

Approved mockup (light by default), not a running app. All names and figures are invented. Pick a screen; the last button switches between light and dark.

Please decide

  • Is the example user right: someone in a small organisation who keeps budgets and lists?
  • Which files matter most: Excel (.xlsx), LibreOffice (.ods) or both? The mockup assumes Excel and CSV.

Not in the first version

  • Charts, pivot tables, several sheets in one file, merged cells, macros, images, comments, printing, sync and shared editing.
